# Luma

Luma is an independent Android TV and Fire TV IPTV player with a cinematic home screen and remote-friendly navigation.

## Download

The latest Android APK is available from the **Releases** page. The app package is `app.luma.tv`.

## Features

- M3U playlists over HTTPS.
- Standard Xtream-compatible live TV, movie, and series APIs over HTTPS.
- Optional XMLTV guide address; standard Xtream XMLTV endpoint fallback.
- HLS and DASH playback through AndroidX Media3.
- Search, category rows, favourites, and TV guide.
- Playlist URL and account details encrypted locally with Android Keystore.

Provider compatibility varies. Modified Xtream APIs, HTTP-only servers, unsupported DRM, or extra authentication headers may not work. Luma does not include channel lists, accounts, or stream URLs. Use only content and subscriptions you are authorized to access.
